# Data-Analyst-Job-Market-Analysis

📌 Project Overview

This project explores job market data to identify the factors associated with Data Analyst salaries and understand the skills and experience required across different roles.

The main goal is to answer questions such as:

How strongly is experience associated with salary?
Which skills are most common in Data Analyst job postings?
Which skills are more prevalent in high-paying positions?
How does salary vary across job requirements and locations?
Is the number of required skills associated with higher salaries?

📊 Dataset Features

Key variables include:

Name — Job title
Years_of_experience — Required experience
Min_Salary — Minimum salary
Max_Salary — Maximum salary
Avg_Salary — Average salary
Skills — Required skills
Work_arrangement — Remote, Hybrid, or In-Office
Location — Job location
Region — Geographic region
English_level — Required English level
Job_url — Original job posting
